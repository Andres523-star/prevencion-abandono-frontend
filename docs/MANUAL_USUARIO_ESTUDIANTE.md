# Manual de Usuario · Rol Estudiante

Este manual describe las acciones que puede realizar un estudiante:
1. **Ficha Personal**: Consultar el estado de notas del semestre, inasistencias y factores de alerta.
2. **Historial Académico**: Ver la evolución de notas de semestres anteriores.
3. **Chat de Acompañamiento**: Comunicarse con tutores y psicólogos de bienestar.
4. **Asistente IA**: Hacer preguntas rápidas sobre reglamentos y horarios de asesoría.
